# BANK-CUSTOMER-CHURN-ANALYSIS

# Bank Customer Churn Analysis

## Project Overview

Customer churn is one of the most critical challenges faced by banks, as losing existing customers directly impacts revenue and business growth. This project focuses on analyzing customer behavior and identifying the key factors that contribute to customer attrition.

Using Python, data visualization libraries, and Streamlit, the project explores customer demographics, account activity, product usage, and engagement patterns to uncover actionable insights. Through exploratory data analysis (EDA) and interactive dashboards, the project helps understand which customers are more likely to leave and provides recommendations to improve customer retention.

## Objectives

* Analyze customer churn patterns and trends.
* Identify factors influencing customer attrition.
* Visualize churn behavior using interactive charts and dashboards.
* Generate business insights for customer retention strategies.
* Build an interactive Streamlit application for data exploration.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* Streamlit
* Jupyter Notebook

## Key Insights

* Overall customer churn rate is approximately 20%.
* Germany has the highest churn rate among all regions.
* Female customers churn slightly more than male customers.
* Inactive customers are significantly more likely to leave.
* Customers with fewer banking products exhibit higher churn rates.

## Business Recommendations

* Improve customer engagement through personalized offers.
* Implement loyalty and retention programs.
* Promote cross-selling of banking products.
* Monitor inactive customers proactively.
* Utilize predictive analytics to identify high-risk customers.

This project demonstrates how data analytics can be leveraged to understand customer behavior and support data-driven decision-making in the banking industry.
